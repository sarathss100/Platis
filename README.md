# CAD Nesting & Plate Optimization Software

## Goal

Build an industrial-grade software system that automatically arranges different shapes on standard rectangular plates with minimum material waste.

The system will:

- Import CAD/DXF drawings
- Arrange parts efficiently on sheets
- Minimize scrap/waste
- Support rectangular and irregular shapes
- Generate optimized cutting layouts
- Integrate with AutoCAD
- Use optimization algorithms and AI heuristics

---

# Vision

Input:

- Plate Size: 6000 x 1500
- Multiple parts of different sizes and shapes

Output:

- Optimized layout
- Material utilization %
- Scrap analysis
- DXF/AutoCAD output
